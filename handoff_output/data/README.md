# Synthetic input example

These files are generated by `../sim/run_application.py`, using `accelerated.initial(300,8,1000,0)`. They are not observations of actual students.

- `synthetic_people_seed1000_k8.csv`:300 unique person IDs and their initial support for an illustrative campus policy, sampled independently from Uniform(0,1) after graph generation.
- `synthetic_contacts_seed1000_k8.csv`:1200 unique undirected edges, one row per unordered pair, on the same300 agents. No self-links or duplicated edges.

Opinion0 represents full opposition and1 full support. Person IDs have no identifying meaning. The initial graph is sampled uniformly from simple graphs with this fixed edge count; the algorithm does not guarantee connectivity.

The simulation initializes directly from the recorded seed convention. These two files expose one actual generated input population for inspection. They are not currently imported into AnyLogic: Java generates its own synthetic population and is compared through deterministic fixtures and replication distributions.

No empirical dataset, demographic estimate or real-time calibration is used. All application outputs and their factors/seeds are in `../sim/application_snapshots.csv`; repeated horizons are not independent replications.
